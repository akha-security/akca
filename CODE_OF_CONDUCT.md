# Code of Conduct

## Our standard

AKCA contributors and maintainers are expected to create a respectful,
professional, and technically constructive community. Healthy participation
includes:

- Giving and receiving specific, evidence-based feedback
- Respecting different backgrounds, experience levels, and viewpoints
- Keeping security discussions responsible and within authorized scopes
- Protecting credentials, personal information, and private target data
- Focusing disagreement on ideas, code, tests, and observable behavior

Harassment, threats, discrimination, deliberate disclosure of private data,
sexualized conduct, sustained disruption, and encouraging unauthorized security
testing are not acceptable.

## Scope

This policy applies in repository issues, pull requests, discussions, code
reviews, and other spaces where someone represents the AKCA project.

## Enforcement

Maintainers may edit or remove contributions that violate this policy and may
temporarily or permanently restrict participation. Serious or repeated behavior
should be reported privately to the repository maintainers. Reports will be
reviewed fairly and kept confidential where reasonably possible.

## Security reports

Security vulnerabilities in AKCA follow the separate private process described
in [SECURITY.md](SECURITY.md). Third-party target findings must never be posted
to this repository without the affected owner's authorization.
